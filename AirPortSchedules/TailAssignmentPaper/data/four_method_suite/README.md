# Four-method A-only suite

This folder is generated by `experiments/run_four_method_suite.py`. It is a
reproducible test suite for the four A-only implementations:

- `legacy_paper_c13`: Khaled et al. cumulative-hour row.
- `legacy_endpoint_split`: endpoint-split legacy row.
- `legacy_corrected`: explicit exact cumulative-state legacy model.
- `event_based`: ordered event-based model.

The suite has two regression cases copied from `data/instances/` and a
performance grid generated with overnight A maintenance:

- Regression: `c13_loophole_test.json` and `event_vs_legacy_clean_test.json`.
- Performance: `P` in `{5, 10, 20, 40}`, `H` in `{7, 15, 30}`, one case per cell.

For the extended heavy grid, use `--extended` with `P` in `{10, 20, 30, 40,
50}` and `H` in `{7, 15, 30, 40, 50}`. Supply `--suite-dir` and `--output`
to keep its 100 performance rows separate from the default suite.

All methods receive the same JSON file for each case. The runner records
status, objective, active variables, active constraints, build time, solver
CPU time, and wall time in `results/tables/four_method_suite.csv`.
It also writes formulation-level performance means and status counts to
`results/tables/four_method_suite_summary.csv`.

The C13 loophole regression intentionally fixes a physically violating
assignment. Its expected statuses are: paper row `optimal`, endpoint split
`optimal`, corrected exact state `infeasible`, and Event-based `optimal`.
That infeasibility is the expected correctness verdict for the fixed bad
pattern, not a performance failure. The clean regression and all generated
performance cases are expected to solve optimally for all four methods.

Generate cases:

```powershell
py -3 experiments/run_four_method_suite.py --generate
```

Run with the requested CPLEX installation:

```powershell
py -3 experiments/run_four_method_suite.py --run `
  --solver cplexamp `
  --executable F:/Progs/IBM.ILOG.CPLEX.for.AMPL.v12.6-EAT/CPLEXamp.exe `
  --time-limit 60
```

Extended run:

```powershell
py -3 experiments/run_four_method_suite.py --generate --run --extended `
  --suite-dir data/four_method_suite_extended `
  --output results/tables/four_method_suite_extended.csv `
  --solver cplexamp `
  --executable F:/Progs/IBM.ILOG.CPLEX.for.AMPL.v12.6-EAT/CPLEXamp.exe `
  --time-limit 900
```
