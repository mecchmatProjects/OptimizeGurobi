%%==========================================================================
\section{Ordered Event-Based Reformulation for a Flight-hour Maintenance}
\label{sec:event_reformulation}
%%==========================================================================

The historical immediate-start ordered formulation processes flights in
nondecreasing departure-time order and represents maintenance by an event
attached to its triggering flight, without successor-arc variables. The
uniform flexible extension below retains this event index but adds bounded
actual-start-day selectors. It therefore is not fully day-free. The ordered
position index $r$ maps to a flight index $i_r$ and is used for assignments,
hour states and event triggers.

The formulations in this section are for type-A checks only. The optional
flexible-start variant E14$_{\mathrm{flex}}$--E21$_{\mathrm{flex}}$ also
models only A-check timing; it does not include the B/C/D maintenance
hierarchy. Its computational implementation uses a one-minute time grid and a
1440-minute maximum deferral window.

\subsection{Ordered event representation}

For flight $i$, let $o_i$ and $a_i$ be its departure and arrival airports,
$p_i$ its flying time, and $\tD{i}$ and $\tI{i}$ its departure and arrival
timestamps (the same macros as in \Cref{sec:basic}). For aircraft $j$, let $a^0_j$ be its initial airport.

Define the ordered-position index set
\[
\mathcal{R}=\{1,\ldots,n_f\},
\]
and let $(i_1,\ldots,i_{n_f})$ be flights sorted by $(\tD{i},i)$. Position
$r\in\mathcal{R}$ refers to flight $i_r$. This is the only role of $r$: it is
an order index over flights. Write $p_r=p_{i_r}$ and $c_{rj}=c_{i_rj}$,
and define $\F^M=\{i\in\F:a_i\in\MA\}$. Define
\[
\mathcal{R}^M=\{r\in\mathcal{R}: i_r\in\F^M\},
\]
and let $\mathcal{Z}$ be the set of admissible event pairs $(r,j)$ for which
flight $i_r$ can trigger the single type-A check on aircraft $j$.
Use the following A-only variables:
\paragraph{E1-E3. Ordered event variables.}
\begin{itemize}
\item $x_{rj}\in\{0,1\}$: aircraft $j$ operates flight $i_r$;
\item $z_{rj}\in\{0,1\}$: a type-A maintenance event is performed after flight $i_r$ on aircraft $j$;
\item $h_{rj}\ge 0$: cumulative type-A flight time of aircraft $j$ immediately after processing position $r$.
\end{itemize}
For inadmissible event pairs, set $z_{rj}=0$ rather than instantiate a
variable. These zero values are used in the prefix-state rows at all
ordered flight positions.
Because $r\leftrightarrow i_r$ is one-to-one, the relation to the original
notation is direct: $x_{rj}=x_{i_r j}$ and $z_{rj}=z_{i_r jd}$ for the
corresponding arrival day $d$; the check type is always A in this section.

A maintenance event after flight $i_r$ is assignment-linked and starts at its
arrival time. The corrected airport-continuity, turn-time, and overlap constraints remain
active on the assignment variables. In particular, an assignment is allowed
only when it can be connected to the aircraft's preceding assigned flight and
when the required maintenance duration leaves enough time before the next
assigned departure.

The objective is
\begin{equation}
\min\ \sum_{r\in\mathcal{R}}\sum_{j\in\Pc}c_{rj}x_{rj}
 +\sum_{r\in\mathcal{R}^M}\sum_{j\in\Pc}mc_{rjA}\,z_{rj}.
\label{eq:ordered_event_objective}
\end{equation}

The event formulation numbers its route constraints independently: E4 is flight
coverage, E5 is non-home continuity, E6 is home-airport continuity and
turn-time balance, and E7 is pairwise non-overlap. E1--E3 are the variable
domains defined above. Maintenance enters through event assignment (E8),
maintenance blocking (E14) and maintenance capacity (E15).

\paragraph{E8. Event assignment.}
Events satisfy
\begin{equation}
z_{rj}\le x_{rj},
\qquad \forall (r,j)\in\mathcal{Z},
\label{eq:ordered_event_assignment}
\end{equation}
The integer event-count link in~\eqref{eq:ordered_c11_recovery} is an auxiliary C11
aggregation, not a separate E family. Timestamp-based incompatibility rows are E14;
they prevent an event from being followed by a departure before the
maintenance duration and turn time have elapsed.


\subsection{Prefix-state propagation}

Let $T_F:=T^A_{\max}$ be the maximum flying time between type-A maintenance events and let $\Phi_j$
be the pre-horizon accumulated flying time of aircraft $j$. At every ordered
position, an unassigned flight carries the state forward, an assigned flight
adds its duration, and an event resets the state after its triggering flight.
Using valid position-specific big-$M$ values $M_{rj}$, the transition is
represented by
\paragraph{E9--E13. Prefix-state propagation.}
\begin{align}
h_{rj}&\ge h_{r-1,j}-M_{rj}x_{rj},\\
h_{rj}&\le h_{r-1,j}+M_{rj}x_{rj},\\
h_{rj}&\ge h_{r-1,j}+p_{r}-M_{rj}(1-x_{rj})-M_{rj}z_{rj},\\
h_{rj}&\le h_{r-1,j}+p_{r}+M_{rj}(1-x_{rj})+M_{rj}z_{rj},\\
h_{rj}&\le T_F(1-z_{rj}),\\
h_{r-1,j}+p_r&\le T_F+M^{\mathrm{pre}}_{rj}(1-x_{rj})
\label{eq:ordered_hour_transition}
\end{align}
The first two rows (E9--E10) carry the state at an unassigned position. The next two
rows (E11--E12) impose accumulation for an assigned flight unless an event is selected.
The first E13 row resets the post-event state to zero when $z_{rj}=1$. The second
E13 row is the pre-event threshold guard: the flight cannot arrive over the
flight-hour limit and then use the event to reset the state. Here
$M^{\mathrm{pre}}_{rj}$ is sufficiently large to deactivate the guard when
$x_{rj}=0$. With valid $0\le\Phi_j\le T_F$, a common sufficient choice is
$M_{rj}=T_F+p_r$ and $M^{\mathrm{pre}}_{rj}=p_r$. The implementation uses
separate tighter constants for the carry and accumulation rows.
The initial state is $h_{0j}=\Phi_j$.

\subsection{Maintenance blocking and capacity constraints}

In the immediate-start model, every maintenance event begins upon arrival of
its triggering flight. Let $\delta_A$ be the duration of the type-A check and
let $\Delta t$ be the minimum post-maintenance turn time.

\paragraph{E14. Maintenance blocking (C8).}
For an event $(r,j)$, define the incompatible following-flight set
\begin{equation}
F^{\mathrm{dep}}_{r}=\left\{\ell\in\F:\ \aD{\ell}=\aI{i_r},\ 
	\tI{i_r}\leq\tD{\ell}<\tI{i_r}+\delta_A+\Delta t\right\}.
\end{equation}
If $z_{rj}=1$, every selected incompatible flight is blocked:
\begin{equation}\label{eq:E14}
x_{\ell j}+z_{rj}\leq1,
\qquad \forall \ell\in F^{\mathrm{dep}}_{r},\ j\in\Pc.
\end{equation}
Only feasible $(\ell,j)$ assignment arcs are generated. Restricting $\ell$ to departures from
the station $\aI{i_r}$ where the check takes place loses nothing: by E5--E6 the aircraft cannot
leave from anywhere else without first operating an intervening flight, which the same family
already blocks.

For an admissible assignment arc, the same blocking condition can be written
with an arc-specific big-$M$ value:
\begin{equation}\label{eq:E14_rewritten}
\begin{aligned}
\tD{\ell}+M_{r\ell}(2-x_{\ell j}-z_{rj})
&\ge \tI{i_r}+\delta_A+\Delta t,\\
&\quad \forall r\in\mathcal{R}^{M},\ \ell\in\F,\ j\in\Pc,\\
&\qquad (\ell,j)\text{ admissible},\ \aD{\ell}=\aI{i_r},\ \tD{\ell}\geq\tI{i_r}.
\end{aligned}
\end{equation}


\paragraph{E15. Maintenance capacity (C10).}
For each possible event start $\theta_r:=\tI{i_r}$, define the active event set
\begin{equation}
\mathcal{E}(a,\theta)=\left\{(q,j)\in\mathcal{Z}:\aI{i_q}=a,\quad
\theta_q\leq \theta<\theta_q+\delta_A\right\},
\qquad \theta_q:=\tI{i_q}.
\end{equation}
At every possible event start, active maintenance occupancy satisfies
\begin{equation}\label{eq:E15_not_full}
\sum_{(q,j)\in\mathcal{E}(a,\theta_r)}z_{qj}
\leq \operatorname{mcap}_{a},
\qquad \forall a\in \MA,\ r\in\mathcal{R}^{M}.
\end{equation}

Each event occupies the half-open interval
$[\theta_q,\theta_q+\delta_A)$. Since all A-check windows have equal length,
checking occupancy at every event start enforces capacity at every time.

Constraints~\eqref{eq:E14} and~\eqref{eq:E15_not_full} enforce maintenance
blocking and station capacity, but they force every check to start on arrival.
If the bay is occupied when an aircraft arrives, the aircraft cannot be
assigned a check after that flight, even though a short wait could make the
check operationally feasible.

\subsection{Flexible-start extension}
\label{subsec:flex_extension}

To remove this restriction, we introduce a variable for the completion time of
each maintenance event, which lets the model defer a check within a bounded
window. Let $W$ be the maximum allowed waiting time between the triggering
flight's arrival and the start of its A-check. We use a time grid of resolution $\tau$
(one minute for the instances considered here); all timestamps, $\delta_A$,
$W$, and maintenance offsets are multiples of $\tau$. For each admissible
event $(r,j)$, let $s_{rj}$ be the offset from the arrival of $i_r$ to the
completion of the check. Its maintenance interval is
\begin{equation}\label{eq:flex_window_for_E16}
\left[\tI{i_r}+s_{rj}-\delta_A,\ \tI{i_r}+s_{rj}\right),
\end{equation}
so $s_{rj}=\delta_A$ gives immediate start and $s_{rj}-\delta_A$ is the
deferral. Define $\mathcal{B}^{W}$ as the set of triples $(r,\ell,j)$ for
which $(r,j)\in\mathcal{Z}$, $(\ell,j)$ is an admissible assignment arc,
$\aD{\ell}=\aI{i_r}$, and
$\tI{i_r}\leq\tD{\ell}<\tI{i_r}+\delta_A+W+\Delta t$.

\paragraph{E14$_{\mathrm{flex}}$. Aircraft blocking.}
If event $(r,j)$ is selected, aircraft $j$ cannot depart on a following flight
until the check and post-maintenance turn time are complete:
\begin{equation}\label{eq:E14_flex}
\tD{\ell}+M_{r\ell}(2-x_{\ell j}-z_{rj})
\geq \tI{i_r}+s_{rj}+\Delta t,
\qquad \forall (r,\ell,j)\in\mathcal{B}^{W}.
\end{equation}
Here $M_{r\ell}$ is an event--flight-specific valid relaxation value; for
example, it may be chosen no smaller than
$\max\{0,\tI{i_r}+\delta_A+W+\Delta t-\tD{\ell}\}$.

\paragraph{E15$_{\mathrm{flex}}$. Deferral bounds.}
The event cannot finish before the A-check could be completed, and its start
cannot be delayed by more than $W$:
\begin{equation}\label{eq:E15_flex}
\delta_A z_{rj}\leq s_{rj}\leq(\delta_A+W)z_{rj},
\qquad s_{rj}\in\tau\mathbb{Z}_{+},\quad \forall (r,j)\in\mathcal{Z}.
\end{equation}
Thus $s_{rj}=0$ when the event is not selected.

\paragraph{E16$_{\mathrm{flex}}$. Realized event time.}
By E4 and E8, at most one aircraft can be assigned an event after any one
flight. Define the selected-event indicator $\zeta_r$, the realized offset
$S_r$, and its completion time $T_r$ by
\begin{equation}\label{eq:E16_flex}
\zeta_r=\sum_{j:(r,j)\in\mathcal{Z}}z_{rj},\qquad
S_r=\sum_{j:(r,j)\in\mathcal{Z}}s_{rj},\qquad
T_r=\tI{i_r}+S_r,
\qquad r\in\mathcal{R}^{M}.
\end{equation}
The explicit uniqueness row E21$_{\mathrm{flex}}$ below records the at-most-one
property used by these aggregates.

Let $\mathcal{W}$ contain the ordered pairs of event-trigger flights at the
same maintenance airport, including every diagonal pair $(r,r)$. A pair may
be omitted only if bounds on its possible event times prove the two maintenance
intervals cannot overlap. For each distinct $(r,q)\in\mathcal{W}$, let
$D_{rq}=T_q-T_r$. Binaries $u_{rq},v_{rq}\in\{0,1\}$ encode the two
inclusive grid comparisons that characterize whether event $q$ is active at
the start of event $r$. Let $u_{rq}=1$ exactly when $D_{rq}\leq0$ and
$v_{rq}=1$ exactly when $D_{rq}\geq-\delta_A+\tau$. Since
$T_r\in[\tI{i_r},\tI{i_r}+\delta_A+W]$, one valid pair-specific choice is
$M_{rq}\geq\max\{|L_{rq}|,|U_{rq}|\}+\delta_A+\tau$, where
$L_{rq}=\tI{i_q}-\tI{i_r}-(\delta_A+W)$ and
$U_{rq}=\tI{i_q}-\tI{i_r}+\delta_A+W$. These comparisons are encoded by
\begin{align}
D_{rq}&\leq M_{rq}(1-u_{rq}), &
D_{rq}&\geq \tau-M_{rq}u_{rq},
\label{eq:E17_flex}\\
D_{rq}&\geq-\delta_A+\tau-M_{rq}(1-v_{rq}), &
D_{rq}&\leq-\delta_A+M_{rq}v_{rq},
\label{eq:E18_flex}
\end{align}
for distinct $r,q$. The grid assumption makes the complements exact: if
$D_{rq}>0$, then $D_{rq}\geq\tau$; if $D_{rq}\not\geq-\delta_A+\tau$,
then $D_{rq}\leq-\delta_A$.

\paragraph{E19$_{\mathrm{flex}}$. Active-at-start indicator.}
For each ordered pair at the same airport, let $o_{rq}$ indicate that both
events are selected and event $q$ is active when event $r$ begins, with
$o_{rq}\in\{0,1\}$. For
$r\neq q$, impose
\begin{equation}\label{eq:E19_flex}
\begin{aligned}
o_{rq}&\leq\zeta_r, & o_{rq}&\leq\zeta_q,\\
o_{rq}&\leq u_{rq}, & o_{rq}&\leq v_{rq},\\
o_{rq}&\geq\zeta_r+\zeta_q+u_{rq}+v_{rq}-3.
\end{aligned}
\end{equation}
For diagonal pairs set $o_{rr}=\zeta_r$. Consequently,
$o_{rq}=1$ exactly when $\zeta_r=\zeta_q=1$ and
$T_q\in[T_r-\delta_A+\tau,T_r]$, which is precisely the half-open interval
overlap test at the start of event $r$ on the $\tau$-grid.

\paragraph{E20$_{\mathrm{flex}}$. Station capacity.}
All A-check intervals have equal duration, so maximum station occupancy is
attained at the start of a selected event. At every such start, impose
\begin{equation}\label{eq:E20_flex}
\sum_{q:(r,q)\in\mathcal{W}}o_{rq}
\leq \operatorname{mcap}_{\aI{i_r}}\,\zeta_r,
\qquad r\in\mathcal{R}^{M},
\end{equation}
The self term $o_{rr}=\zeta_r$ counts the
event whose start is being checked.

\paragraph{E21$_{\mathrm{flex}}$. Event uniqueness.}
At most one aircraft can receive an event after a given triggering flight:
\begin{equation}\label{eq:E21_flex}
\sum_{j:(r,j)\in\mathcal{Z}}z_{rj}=\zeta_r\leq1,
\qquad r\in\mathcal{R}^{M}.
\end{equation}
This row is implied by E4 and E8, but is stated explicitly to make the event
aggregates in~\eqref{eq:E16_flex} unambiguous.

The overlap rows are exact on the stated time grid; no binary is merely
penalized toward indicating an overlap, and no capacity is inferred from a
pairwise-neighbour count. Setting $s_{rj}=\delta_Az_{rj}$ recovers immediate
maintenance timing, so E14$_{\mathrm{flex}}$--E20$_{\mathrm{flex}}$ reduce to
E14--E15. The flexible formulation therefore contains the immediate-start
feasible schedules and can only weakly improve their minimum assignment cost.





\subsection{Remaining rows and correspondence with the day-indexed model}
\label{subsec:event_implementation_strengthening}

The route rows E4--E7 are the corrected basic constraints of
\Cref{sec:basic} written on the ordered index. Flight coverage (E4) is
\begin{equation}
\sum_{j\in\Pc}x_{rj}=1,\qquad r\in\mathcal{R},
\label{eq:ordered_c0_c1}
\end{equation}
E5--E6 are the continuity and turn-time balances~\eqref{eq:c2}--\eqref{eq:c3},
and E7 is the non-overlap family~\eqref{eq:c4_overlap}, optionally
strengthened by maximal cliques as in~\eqref{eq:c5_overlap}. The
calendar-spacing row C12 is deliberately omitted: the hour-only extension
studied here does not impose Khaled et al.'s maximum-spacing rule, and this
omission does not imply that A checks have no calendar requirement.

The daily indicator $y_{jd}$ is not a primitive variable of the event model.
For the immediate-start model, where an event starts on arrival, a day-level
count uses the one-based arrival day
$\bar d_{i_r}=1+\lfloor\tI{i_r}/1440\rfloor$:
\begin{equation}
n_{jd}=\sum_{r:\,\bar d_{i_r}=d}z_{rj},
\qquad j\in\Pc,\ d\in\D,\quad n_{jd}\in\mathbb{Z}_{+}.
\label{eq:ordered_c11_recovery}
\end{equation}
An arrival exactly at midnight belongs to the new day. The historical
implementation indexes these auxiliary arrival-day buckets from zero, so its
bucket $d-1$ corresponds to day $d$ in this notation.
No E-row or objective term uses $n_{jd}$ in the immediate-start model, so it
can be recovered after solution. The uniform flexible model of
\Cref{subsec:uniform_flexible} replaces it by a binary actual-start-day
selector and enforces at most one check per aircraft per calendar day. The
airport-occupancy variable of a time-expanded formulation is not needed:
capacity is represented directly by the timestamp sums E15.

Several families can be reduced without changing the integer feasible set.
With one maintenance type, event-type exclusivity is implied by the binary
domain of $z_{rj}$. The unconditional bound $0\le h_{rj}\le T_F$ can be
imposed as variable bounds, but this does not replace the E13 row
$h_{rj}\le T_F(1-z_{rj})$: that row forces the post-event state to zero and
remains necessary. Identical E15 active-event sets are emitted once, and a
capacity row is dropped when its number of binary terms does not exceed the
capacity. Finally, maximal
interval-clique rows replace the pairwise rows in E7; every conflicting pair
lies in a maximal clique, so the integer feasible set is unchanged. The
reduced form is used in all experiments of \Cref{sec:computational}.
\Cref{tab:ordered_c1_c13} records how each numbered day-indexed requirement is
represented. Some rows disappear because their variables are eliminated; this
is a change of formulation, not an omitted feasibility condition.

\begin{proposition}[Ordered prefix-state validity]
\label{prop:ordered_event_correct}
Assume the corrected route constraints define a physically feasible integral
assignment, every event is attached to an assigned flight at a
maintenance-capable airport, and the supplied initial state is valid. Then the
ordered prefix-state formulation satisfies the type-A flight-hour limit.
\end{proposition}

\begin{proof}
Induct on the ordered flight positions. An unassigned position carries the
state unchanged. An assigned position adds its flying time unless an event is
selected, in which case the reset rows set the state to zero after the current
flight. The final transition row and the upper state bound prevent
the threshold from being exceeded before a reset. The induction starts from
$\Phi_j$, so every assigned route satisfies the type-A limit.
\end{proof}

\subsection{Uniform flexible and day-indexed encodings}
\label{subsec:uniform_flexible}

The uniform main model retains E4--E13 and flexible E14--E21, with one-minute
grid $\tau=1$, maximum start deferral $W=1440$ minutes, a common A-check
duration, and the same assignment and nonnegative check costs in every
encoding. These are experimental assumptions, not parameter values taken
from Khaled. An aircraft remains at its trigger's arrival station until
completion plus turn time; no assigned flight may escape while waiting.
The hour state resets algebraically at the trigger, but blocking ensures
there is no intervening flight before actual completion. Thus the next
assigned flight sees exactly the post-completion state, including when a
check is deferred across midnight.

Let $\sigma_{rj}=\tI{i_r}+s_{rj}-\delta_A$ be the actual start time when
$z_{rj}=1$, and let $b_{rjd}$ select its start day. Candidate days intersect
$[\tI{i_r},\tI{i_r}+W]$. The activated day links and daily limit are
\begin{align}
 \sum_d b_{rjd}&=z_{rj},\\
 (d-1)1440-L_{rd}(1-b_{rjd})&\le\sigma_{rj},\\
 \sigma_{rj}&\le d1440-\tau+U_{rd}(1-b_{rjd}),\\
 \sum_r b_{rjd}&\le1,\\
 b_{rjd}&\in\{0,1\}.
 \label{eq:uniform_start_day}
\end{align}
The links are imposed for every admissible $(r,j,d)$; the last inequality
is imposed for each aircraft-day. Valid constants include
$L_{rd}=\max\{0,(d-1)1440-\tI{i_r}+\delta_A\}$ and
$U_{rd}=\max\{0,\tI{i_r}+W-(d1440-\tau)\}$, allowing the inactive
offset $s_{rj}=0$. An exact midnight start belongs to the new day.

The event-indexed implementation uses $z_{rj}$ and $b_{rjd}$; the
day-indexed implementation makes $z^{D}_{rjd}=b_{rjd}$ its binary decisions
and substitutes $z_{rj}=\sum_d z^{D}_{rjd}$ as an expression in every
assignment, cost, timing and state row. They share the hour engine; they are
not independent implementations of the physical counter.

\begin{proposition}[Equivalence of the uniform encodings]
\label{prop:uniform_equivalence}
Let $\mathcal{S}^{E}$ and $\mathcal{S}^{D}$ be the feasible sets of the
event-indexed and day-indexed encodings, and let $\pi$ map a solution to its
assignments $x$, event indicators $z_{rj}$, offsets $s_{rj}$, start-day
selectors $b_{rjd}$ and hour states $h_{rj}$. Then
$\pi(\mathcal{S}^{E})=\pi(\mathcal{S}^{D})$, the two models have the same
objective on corresponding solutions, and their optimal values coincide.
\end{proposition}
\begin{proof}
Given $(z,b,\dots)\in\mathcal{S}^{E}$, set $z^{D}_{rjd}=b_{rjd}$; the
substitution $z_{rj}=\sum_d z^{D}_{rjd}=z_{rj}$ leaves every row and the
objective unchanged. Conversely, given a day-indexed solution, set
$b_{rjd}=z^{D}_{rjd}$ and $z_{rj}=\sum_d z^{D}_{rjd}$. Assignment linking
($z_{rj}\le x_{rj}\le1$) bounds this nonnegative integral sum by one, so
$z_{rj}$ is binary, and the day links locate the selected start uniquely on the
grid. All other rows are identical under the substitution, which proves both
inclusions.
\end{proof}

The proposition is a statement about encodings: it says that the day-indexed
variables can be eliminated by substitution, not that the two models differ in
LP strength or solution effort. Both share the hour engine, so it should not
be read as independent confirmation of the physical hour counter. That
confirmation is provided by the chronological replay of \Cref{sec:computational}.

For the fixed-night comparison, restrict selected starts to 22:00 on a
candidate day, still within the same $W$ window. The time 22:00 is a stated
study convention, not a specification in the original paper. All remaining
constraints, including concurrent bay capacity, are retained. Therefore every
fixed-night schedule is flexible-feasible and
$v_{\mathrm{flex}}\le v_{\mathrm{night}}$ when both optima are finite.
This is a restriction, not a lower-bound relaxation or a literal reproduction
of Khaled's daily-quota model. Daily interval/prefix rows are studied only
under their day-boundary reset assumptions, not as exact flexible models.

Daily indicators add up to
$O(n_m n_p(1+\lceil W/1440\rceil))$ variables and links. With $W=1440$
their support is bounded per event, but it would be misleading to call the
uniform model fully day-free. Independent chronological replay and the
tiny start-time enumeration test, rather than the shared state engine alone,
provide additional correctness checks.

\subsection{Historical immediate-start model: complexity and size}

Let $n_f=|\F|$, $n_p=|\Pc|$, and let $n_m$ denote the number of flights
that arrive at a maintenance-capable airport. In the A-only ordered model,
the assignment variables contribute at most $n_fn_p$ binary variables, while
the maintenance-event variables contribute at most $n_mn_p$ binary variables.
The aircraft-local prefix state contributes at most $n_fn_p$ continuous
variables; with sparse aircraft eligibility, all three counts are smaller and
are determined by the feasible $(i,j)$ pairs. Thus the principal variable
bound is
\[
O(n_fn_p+n_mn_p),
\]
with no additional day-indexed $y_{jd}$ or occupancy-state $q_{a,j}$ family.
The ordered implementation instead stores one state position per feasible
flight--aircraft pair.

The main linear constraint families are $O(n_f)$ for coverage,
$O(n_fn_p)$ for continuity and event assignment, and $O(n_fn_p)$ for the
prefix-state equations. C11 aggregation contributes $O(n_pD)$ equalities for
the event counts, without restricting their values. Pairwise
non-overlap and timestamp blocking depend on the conflict sets and are
$O(|\mathcal{O}|n_p)$ and $O(|\mathcal{B}|)$, respectively, where
$\mathcal{O}$ is the flight-overlap set and $\mathcal{B}$ is the generated set
of event--following-flight blocking pairs. Timestamp-capacity rows are
generated per airport breakpoint, so their number is proportional to the
number of distinct event timestamps rather than to a full time grid. In the
worst case, $|\mathcal{O}|=O(n_f^2)$ and the sparse conflict families can also
be quadratic, but timetable sparsity usually makes their observed counts much
smaller. The theoretical conclusion is therefore precise: the Event-based
model removes the day dimension from the principal variable families and
keeps prefix-state size linear in feasible flight--aircraft pairs; it does not
guarantee fewer total constraints unless the induced conflict and blocking
sets are also sparse.

The ordered formulation combines event-triggered maintenance with a global
flight order and aircraft-local prefix states. It removes the day-pair
accumulation ambiguity of the legacy cumulative-flight-time row, avoids successor-variable
expansion, and keeps the physical route constraints needed for valid tail
assignments. The uniform type-A models omit C12 by choice: the exact
prefix-state recursion enforces the flight-hour limit, but does not impose
Khaled's separate calendar-spacing requirement. The
computational study in
\Cref{sec:computational} evaluates this formulation against the legacy 
model on matched horizon and fleet-size grids.

\subsection{Complexity and model size of the flexible-start variant}
\label{subsec:flex_complexity}

The flexible variant keeps E1--E13 verbatim. It adds one grid-valued offset
$s_{rj}$ per admissible event, at most $n_mn_p$ such variables. The trigger-level
quantities $\zeta_r$, $S_r$, and $T_r$ in~\eqref{eq:E16_flex} are linear
expressions, not additional variables. The principal variable count therefore
remains $O(n_fn_p+n_mn_p)$ before the capacity-comparison binaries are included.

The E14$_{\mathrm{flex}}$ row set $\mathcal{B}^{W}$ spans the widened departure
window $[\tI{i_r},\tI{i_r}+\delta_A+W+\Delta t)$, so its size grows with $W$;
the rows use big-$M$ relaxation rather than the immediate-start set-packing
form. For each ordered pair in $\mathcal{W}$, E17$_{\mathrm{flex}}$ and
E18$_{\mathrm{flex}}$ use two binary comparisons, and
E19$_{\mathrm{flex}}$ uses one overlap binary. E20$_{\mathrm{flex}}$ contributes
one capacity row per possible trigger event, while E21$_{\mathrm{flex}}$ is
implied by E4 and E8. Thus the added capacity model has $O(|\mathcal{W}|)$
binaries and rows. Without pair pruning, $|\mathcal{W}|=O(n_m^2)$; a pair may
be pruned only when its completion-time bounds prove that its windows cannot
overlap. The grid resolution is essential to exactness: it replaces strict
half-open interval comparisons by finite, inclusive integer comparisons.

Fixing $s_{rj}=\delta_Az_{rj}$ recovers the immediate-start maintenance
intervals. E14$_{\mathrm{flex}}$ then reduces to E14, and the capacity rows
check the same occupancy at each selected event start as
\eqref{eq:E15_not_full}. Hence every immediate-start feasible schedule is
feasible for the flexible formulation, and its optimal assignment cost can
only be weakly lower. The aircraft remains grounded until the deferred check
and post-maintenance turn time are complete; the additional freedom concerns
maintenance timing, not flight operation while waiting.
