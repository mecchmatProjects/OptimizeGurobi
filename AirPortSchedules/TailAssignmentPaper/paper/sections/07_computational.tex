\section{Computational Evidence and Reproducibility}
\label{sec:computational}
%%==========================================================================

No computational performance claims are made in this manuscript. Although
the workspace contains exploratory A-only solver outputs, the current
executable model does not implement the interval and opening-period rows
\eqref{eq:a_interval_hours}--\eqref{eq:a_opening_hours} as stated here.
Those outputs therefore cannot validate the formulation presented in this
paper. The available records also do not provide a complete, matching bundle
of source revision, instance hashes, solver configuration, and independently
replayed schedules for the reported runs.

The older tables have consequently been removed rather than presented as
reproductions: the repository's instance generator produces synthetic
instances, and the published computational study used a real-world timetable.
A valid evaluation requires implementing the stated formulation, freezing
the exact source and input files, and recording solver version, time limit,
termination status, incumbent and bound, model size, runtime, and independent
schedule-validation results for each instance. Until those checks are
complete, this section makes no claims about solution quality, scalability, or
comparative performance.
