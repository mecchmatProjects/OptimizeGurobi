\subsection{Implementation and environment}

All models are implemented in Python using Pyomo. The reported exact solves
use unrestricted IBM ILOG CPLEX~12.6 for AMPL through Pyomo's
\texttt{cplexamp} interface. The deterministic instance generator and all
benchmark scripts are included in the companion repository. Every reported
solution is checked independently by replaying the aircraft route and its
maintenance counter.

\subsection{Constraint (11) verification}

The original cumulative-flight-time row and the natural endpoint-split
replacement were evaluated on the hand-built C11 counterexample. The actual
production constraint objects admit complementary violating patterns: the
original row is relaxed when only one endpoint is checked, while the split
replacement is relaxed when both endpoints carry checks. The exact cumulative
state formulation rejects both patterns. This directly confirms the algebraic
analysis in \Cref{subsec:c11_flaw,subsec:c11_corrected}.

\subsection{Ordered type-A event formulation}
\label{subsec:event_measurements}

The ordered implementation removes explicit successor variables and propagates
an aircraft-local prefix state through flights sorted by departure time. A
maintenance event is attached to its triggering flight, and the pre-check row
prevents an event from repairing an already overdue arrival. This is the
latest A-only method evaluated below. The ordered formulation agrees with the
legacy A-only model on every feasible instance reported here.

\subsection{Summary and limitations}

The corrected type-A model rejects the C11 counterexample, while the ordered
A-event implementation preserves objective parity and reduces variable counts
on the tested feasible grids. Its timing advantage is strong in the A-only
horizon experiment and is positive on average in the fleet-size experiment,
but the benchmark contains one instance per cell. The results therefore
support the ordered formulation as a compact and promising A-only method, not
as a solver-independent or distribution-independent runtime guarantee.
